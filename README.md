## What is Java?

Java is a **high-level, object-oriented programming language** designed to build secure, reliable, and platform-independent applications. It became popular because of its **Write Once, Run Anywhere (WORA)** approach, where Java code can run on different platforms through the Java Virtual Machine (JVM).
